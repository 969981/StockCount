## 最终决议（用户确认，2026-11-25）

XTEST 和 COB 统一：操作员只输入存货单位下的实际数量一次。

| XCOUTD | 写入值 |
|---|---|
| PCU_0 | 当前已解析的 XLABELDTL.STU_0 |
| PCUSTUCOE_0 | 固定 decimal 1 |
| QTYSTU_0 | 人工输入数量 |
| QTYPCU_0 | 同一人工输入数量 |

不读取 XLABELDTL.PCU_0 或 PCUSTUCOE_0 作为提交准入条件，不乘除换算，不以 QTY_0 或 QR.QT 覆盖实盘数量。不改数据库结构、不修改历史记录、不新增开关。保留 STU 非空、最大3字符、无控制字符检查，兼容旧客户端错误码 UNIT_MAPPING_UNSUPPORTED（仅表示存货单位无效）。保留数量、单据、库位、标签、同单同箱重复、SQL 事务与 AUUID 原请求查询。

示例：标签 STU=PCS，PCU 为空，标签系数=4000，实盘3950；写入 PCS / 1 / 3950 / 3950。

## 验收

纯业务回归覆盖有效/无效 STU、原包装单位空白/不同以及高系数不参与判断。CI 编译/单测与现场 XTEST 实际 INSERT 分开验收。建议至少测试一个非1标签、数量0、重复扫码与重试，核对四个目标字段。不得把历史统计等同于已完成真机写入测试。
